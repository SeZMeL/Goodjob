# Ridic Warsaw roadmap

## Milestone 0.1
- [x] Android Kotlin and Jetpack Compose project skeleton
- [x] LPG fuel cost calculation core
- [x] Turkish and Polish resource directories
- [x] GitHub Actions debug APK workflow

## Next milestones
- [ ] Editable LPG consumption and price settings
- [ ] Offer calculator: gross fare, pickup distance, trip distance and duration
- [ ] Estimated fuel-adjusted amount and PLN/km, PLN/hour
- [ ] Language selector (Turkish / Polish)
- [ ] Manual trip logging and daily / weekly summaries
- [ ] Permission-led, user-controlled OCR assistance if compliant and technically feasible

The app will not automatically accept trips or call private Uber/Bolt APIs.
High-demand areas and bonuses will only be displayed when backed by a verifiable data source.
